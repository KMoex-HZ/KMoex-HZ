## 📈 Quant & Credit Risk Analytics

### 🏦 Quantitative Risk Analyst Intern — PT Bank Lampung (Jun – Aug 2026)

- Modeled the impact of **BI Rate** on 5 balance sheet components (current accounts, savings, time deposits, total loans, profit/loss) using **ARDL** on monthly data (Mar 2021 – May 2026)
- Selected lag structures via **BIC grid search** (35 specifications) and validated with ADF/KPSS and Breusch-Godfrey tests
- Built **recursive forecasts for Jun–Dec 2026** under 3 BI Rate scenarios (Normal, Moderate, Worst) to support IRRBB stress testing
- Built **ARIMAX** models to forecast BI Rate using the US Fed Rate as an exogenous variable
